Apo 隐私政策

生效日期：2026 年 10 月 15 日

1. 数据存储

Apo 是一款本地优先应用。导入图书与阅读进度保存在您设备的 IndexedDB / 本地文件中；应用没有自建服务器。使用在线搜索、AI、云端 TTS 或音色克隆时，相关关键词、所选正文、朗读文本或录音会直接发送给您选择的第三方服务商。

2. 我们收集的信息

我们不收集、不存储、不分享任何个人信息。应用不含账号系统，不要求登录，不使用第三方统计或广告 SDK。

3. 第三方服务（仅在您主动使用时）

  • 在线搜书：搜索关键词会从您的设备直接发送给 Open Library 与 Project Gutenberg，以返回书目及公版书下载链接。
  • Gemini：只有在您填写 Gemini API Key 并主动使用 AI 搜索扩展、讲解、翻译或多角色功能时，相应的搜索描述或阅读文本才会发送至 Google Gemini。
  • 云端 TTS：使用 ElevenLabs 或自定义服务时，待朗读文本与音色 ID 会发送到相应服务商。
  • 音色克隆：录音或您选择的音频在勾选授权确认并开始克隆后，会发送到所选语音服务商。新克隆成功后，应用仅保存服务商返回的 Voice ID，不保存这次使用的原始录音。
  • 本机设置：服务商 API Key 保存在当前浏览器的本地存储中；清除浏览器数据会一并清除这些 Key。

上述服务的隐私政策请参阅各服务提供方。

4. 权限说明

应用申请的设备权限仅用于实现朗读、文件导入等核心功能，不会用于其他目的。

5. 儿童隐私

本应用不面向 13 岁以下儿童收集任何信息。

6. 政策变更

隐私政策如有变更，将在本页面更新并同步更新生效日期。

7. 联系我们

如有任何隐私相关问题，请通过应用内「我的」页面反馈。

# Readify 视觉设计剖析 + DeepRead 模仿方案

调研日期：2026-10-05。素材：readifyai.com 官网（hero + 2 个功能区）、app.readifyai.com/library 网页版书架（浏览器既有登录态直接渲染出真实产品 UI，未执行任何登录动作）、Chrome 扩展与商店文案。Google Play 截图区被登录墙拦截，未采用。
说明：以下"模仿"指提炼设计语言后做原创实现，不复制其插画、Logo 等美术资产。

## 一、Readify 的视觉设计语言（7 条）

### 1. 纸墨暖色体系
- 基底是暖米白（约 #FAF7F1），全站铺波点网格暗纹；功能区配水墨山水/纸质感插画。
- 深色只出现在两处：左侧导航栏（近黑 #1B1B1D）、黑色实心按钮/徽章。整体是"纸 + 墨"的文人气质，不是科技蓝。

### 2. 衬线大标题 + 无衬线正文
- 营销大标题、App 内"我的书架"标题都用中文宋体风衬线（Noto Serif SC 一类），字号巨大、字重高。
- 按钮、列表、说明文字全部用无衬线。衬线只负责"标题气场"。

### 3. 全胶囊形状语言
- CTA 按钮、顶部悬浮导航（毛玻璃 pill）、搜索框、分段选择器（EPUB/MD/MOBI/PDF…）、进度徽章——全部是全圆角胶囊。
- 卡片用 20px+ 大圆角，无直角元素。

### 4. 黑色实心 CTA
- "免费开始听书""+ 添加"以及书封上的进度徽章（63%、34%…）都是纯黑 pill + 白字。这是全站最强的视觉锚点。

### 5. 书架：深侧栏 + 双区陈列
- 左深色侧边栏：Logo → 我的书架 / 智能搜书 / 划线与笔记 / 我的音色 / 下载 → 底部反馈 + 用户头像。当前项用浅色圆角高亮。
- "最近阅读"：横向滑动卡片（封面左、标题作者右、黑色进度徽章）。
- "全部书籍"：网格陈列，3D 书封（带书脊阴影、微微立体），封面右下角压黑色 % 徽章，标题作者在下方；右上"全部文件/添加时间"筛选下拉。
- 留白极大，信息密度低，靠封面本身撑视觉。

### 6. 播放器：浅色卡片 + 橙色强调
- 播放器为浅色浮层：书籍封面、章节名、播放/暂停、前后 15 秒、语速 1.0×、章节列表、时间线。
- 进度/波形用橙色（约 #E8822A）作为唯一强调色，区别于黑白主调。

### 7. 营销站手法（供官网/引导页参考）
- 大标题内嵌小图标 chips（EPUB 文件图标、紫色圆点、国旗圆点随文走）。
- 手风琴功能列表：当前项左侧一条黑色竖线高亮（"神经网络 TTS / 富有表现力的语调 / 声音克隆…"）。
- 手机样机放在粉色色块上，旁边飘文件格式小卡片（TXT/MOBI/EPUB）。

## 二、DeepRead 现状对照（v3.21）

- v3.10 定调"纯白 Apple 极简"，书架是 `.book-row` 纵向列表（封面+标题+细进度条），标题已用 `var(--serif)`，主强调色为 `--primary`（蓝系）。
- 已有衬线变量、有进度概念、有"最近阅读"数据（progress.idx），缺的是：陈列方式（无网格/横滑）、徽章式进度、黑色 CTA、暖纸主题、播放器强调色。

## 三、模仿方案（分级，全部原创实现）

| 级别 | 项目 | 内容 |
|---|---|---|
| S（小） | 衬线标题统一 | display 标题（书架、阅读页书名、空状态）统一 Noto Serif SC；数字/徽章/按钮保持无衬线 |
| S（小） | 黑色胶囊 CTA | 主按钮（开始阅读、添加、保存）→ 纯黑 pill 白字；次按钮描边 pill |
| S（小） | 空状态插画化 | 空书架改成纸质感插画 + 衬线标题 + 黑色胶囊按钮（抄它的结构，不抄它的图） |
| M（中） | 书架双区重构 | 顶部"最近阅读"横滑卡片行；下方"全部书籍"网格；3D 书封（CSS 书脊阴影）；封面右下角黑色 % 徽章；格式/时间筛选 |
| M（中） | 暖纸主题 | 阅读器新增"暖纸"主题：#F7F2E9 底 + 正文 #2B2620，衬线正文；与纯白/夜间并存 |
| M（中） | 播放器橙色波形 | 迷你播放器进度条改波形式样，强调色换暖橙；保留现有布局 |
| L（大） | 深色侧边栏 | 仅平板/桌面宽屏生效：左侧深色导航 rail；移动端保持底部 Tab（形态不同，精神一致） |

## 四、不建议照搬的
- 它的 AI 生成音色头像（用户评价"creepy"）——DeepRead 音色页保持干净列表。
- 首屏预置示例书（用户抱怨"不想要"）——DeepRead 空书架保持干净，用插画引导代替。
- 标题内嵌 emoji 式 chips（如国旗圆点）——营销站可玩，App 内克制使用。

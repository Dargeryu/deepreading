ElevenLabs 云端语音

免费版每月 1 万字符（约半小时中文朗读），超出后需付费。Key 只存本机。云端音色去「声音 → 云端」试听选用；你在 ElevenLabs 克隆的音色会自动出现在云端列表里。

声音克隆服务

ElevenLabs：POST /v1/voices/add（multipart：name + files），Key 为 xi-api-key。自定义：按服务商文档填接口与字段，返回 JSON 中 voice id 的路径（如 data.voice_id）。克隆出的音色走「自定义 TTS API」引擎朗读。

导入
